# 本片的示意模擬（film simulation）

畫面上的計數是本片自己的模擬，不是量測；畫面上標「示意」。

- 每個工作長度相同（1 單位）；用量額度以「正在跑的工作 × 時間」扣，跑的時候就扣，不是回報時才扣。
- 額度 = 7 個工作長度。
- S1：20 個同時跑，每條各跑到 7/20 = 35% 時額度歸零，全部凍住，回來 0 / 20。
- F4：一次只跑 2 個，額度一樣：前 3 組（6 個）跑完，第 4 組跑到一半時額度歸零，已收 6 / 20。
- E1：只看速率上限（同時在跑的數量不超過下游上限），沒有額度條；不被 429 退件，回來 20 / 20。限住同時在跑的數量不會讓總花費變少。
